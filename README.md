# Smart_Feedback

A feedback collector with sentiment analysis, a voice input option, and interactive visualization of the collected feedback.

---

## 📌 Overview

Smart_Feedback is a web-based feedback collection system that goes beyond a simple form. It analyzes the sentiment of each submission using NLP, supports voice input for accessibility and ease of use, and presents the collected feedback through interactive charts so patterns are easy to spot at a glance.

## 🧠 Key Features

🔹 Feedback collection form
🔹 Sentiment analysis on submitted feedback (NLP)
🔹 Voice input option for feedback
🔹 Interactive charts/visualization of results
🔹 Admin dashboard to view feedback trends

## ⚙️ Technologies Used

- Python 🐍
- NLP (Sentiment Analysis)
- HTML, CSS, JavaScript 🌐
- Speech-to-text for voice input

## 🏗️ System Architecture

1. User submits feedback via form or voice input
2. Voice input is converted to text
3. Sentiment analysis model processes the feedback
4. Results are stored and aggregated
5. Dashboard displays interactive visual summaries

## 🚀 Getting Started

### Installation
```bash
git clone 
cd smart-feedback-sentiment-analysis
pip install -r requirements.txt
```

### Run the Project
```bash
python app.py
```
